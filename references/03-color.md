# 03 色彩

**唯一来源：品牌视觉板 SVG 原文件（用户确认：以 SVG 原文件为准）。** 视觉板只给出色块，以下角色分配为【新增规范】，色值本身为官方。

一组紫色色阶负责身份，墨黑与灰白构成空间，珊瑚橙是唯一强调色。Logo 渐变只属于 Logo。

- 旧 v1.0 变量名（--nx-purple-hover、--nx-orange、--nx-dark-navy、--nx-purple-soft 等）在 tokens.css 中保留为兼容别名，已指向新色值，新代码请用上表名称。

## 比例【新增规范】
白/浅灰 55% · 墨黑 20% · 奈势紫 ≤ 10% · 薰衣草紫/雾紫 ≈ 8% · 深紫少量 · 珊瑚橙 ≤ 5%（每版一处）。营销物料可用墨黑作主背景（≤ 60%，同视觉板深色卡）。

## 对比度（WCAG 2.x：正文 ≥ 4.5，大字 / 图标 / 控件边界 ≥ 3；向下取两位小数）
完整报告见 `contrast-report.md`。
- 白 / #6857E7 = 5.11 ✓（奈势紫按钮白字）
- 白 / #3C237C = 12.18 ✓；白 / #262626 = 15.13 ✓
- #BBBBFE / #262626 = 8.39 ✓（墨黑底强调文字；旧稿曾记 8.40）
- #6857E7 / #262626 = 2.95 ✕ 墨黑底不用奈势紫文字（改用 #BBBBFE 或白色）
- #262626 / #FF604A = 5.06 ✓；白 / #FF604A = 2.98 ✕ 珊瑚橙底必须用墨黑字，禁止白字
- #FF604A / 白 = 2.98 → 白底不用珊瑚橙做文字。唯一例外：品牌大字（≥48px）用独立定值 #E5503A（对白 3.79），不是色阶档；色块、图形、按钮仍用 #FF604A
- 强调按钮悬停 #FA5B46 / 墨黑 = 4.79 ✓；按下 #F75742 / 墨黑 = 4.60 ✓
- #6857E7 / #F1F0FD = 4.54 ✓；#6E6E73 / 白 = 5.07 ✓；#6E6E73 / #F6F6F8 = 4.69 ✓

## 印刷
#6857E7 与 Logo 渐变紫 #7417FF 都超出四色色域，印刷偏灰属正常；背景板、Logo 墙、礼品等重要物料由品牌组指定专色，以色卡 + 实物打样确认，同批物料同一印厂。

## v1.3 / v1.3.2 语义色与深色模式
界面不要硬编码上表近似色，改用 `assets/tokens/tokens.css` 的语义层 `--nx-color-*`。Token 分三层：原始色 → 色阶 → 语义色，细则见 `14-tokens-v1.3.md` 与 `spec-v1.3.md`。

- 主按钮：`--nx-color-accent` #6857E7，悬停 `--nx-color-accent-hover` #5F4AD4，按下 `--nx-color-accent-pressed` #5743B7（深色按下为色阶 #5742B8），文字白色。
- 破坏性/强调按钮：`--nx-color-button-danger` #FF604A 配墨黑（5.06:1），悬停 #FA5B46（4.79:1），按下 #F75742（4.60:1）；浅色与深色相同。不要改全局 `--nx-color-error`。
- 深色模式页面底为中性墨黑 #262626。开关：`[data-theme="dark"]` 与 `prefers-color-scheme`；品牌站把选择存在 `localStorage` 键 `nx-theme`。
- 深色错误 Toast：底 #B42318，字 #F6F6F8（6.09:1）。深色错误文字和图标 #F78676。深色 error 强填充 #E8705F 配墨黑（4.98:1）只用于状态，不作强调按钮。
