# 13 品牌管理

## 审批流程【建议稿，角色需确认】
① 需求方填写需求单 → ② 从素材库取模板制作 → ③ 对照 Skill 清单自检 → ④ 品牌组审核 → ⑤ 打样 / 预览确认 → ⑥ 发布并归档

| 分级 | 范围 | 审核 | 时效 |
|---|---|---|---|
| A 级 · 必审 | Logo 墙、背景板、展台、官网首页、App 图标、对外画册、联合发布、合作方 Logo 并列 | 品牌负责人 + 业务负责人（涉及法律表述加法务） | 3 个工作日 |
| B 级 · 抽审 | 海报、单页、活动物料、社媒封面模板、对外 PPT | 品牌组 | 1 个工作日 |
| C 级 · 自检 | 日常社媒图文、内部 PPT、邮件签名、名片（按模板） | 制作人按清单自检，品牌组每月抽查 | 即时 |

## 文件命名【新增规范】
`NexAI_类别_名称_规格_版本_日期`，如 `NexAI_海报_Agent冲刺_60x90cm_v2_20261102.pdf`
- 类别：Logo / 海报 / 单页 / PPT / 社媒 / 视频 / 活动 / 办公
- 版本：v1、v2…；定稿加 `_final`，不用"最终版2""最最终"
- 日期 8 位 YYYYMMDD；不用空格与特殊符号

## 常见问题
- **Logo 能换节日色吗？** 不能。节日氛围通过背景、插画和小奈道具表达。
- **合作方要求 Logo 一样大？** 联合发布可视觉等高、竖线分隔，走 A 级审批；常规场合合作方 Logo 小于奈势AI。
- **找不到某尺寸模板？** 用最接近的模板改尺寸，保持 Logo 位置与标题层级；交品牌组补入素材库。
- **能用 AI 画小奈新动作吗？** 可做内部草图，不可对外发布；正式动作用 3D 模型出图并审核入库。
- **英文材料怎么写品牌名？** NexAI；中文材料写奈势AI，首次出现可写"奈势AI（NexAI）"。
- **官网怎么写？** nexai.link，全小写、不加 www、无结尾斜杠；需可点击链接时写 https://nexai.link。
