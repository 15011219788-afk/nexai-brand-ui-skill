# 07 数字产品：网站 · App · 小程序

数字产品完整沿用现有《NexAI 品牌 UI 规范》（仓库 nexai-brand-ui-skill：design-tokens / components / page-patterns / content-and-trust / qa-checklist）。本文件是各端共用的核心规则。

## 网站（沿用）
- 首页聚合顺序：Banner → AI护照 → PBL实战项目 → 精选活动 → 专业认证 → 机会。
- 深色 Hero（#262626）只承载一个主信息与一个主行动；示例数据仅作版式示意，不得当真实数据发布。
- 页脚含横版 Logo 与官网 nexai.link。

## App 与小程序（组件沿用；移动端导航为【建议稿】）
- App 顶栏居中 Logo，顶栏高 58px。
- 小程序自定义导航：Logo 与标题左对齐，避让右上角胶囊按钮。
- 底部 Tab ≤ 5 个（具体栏目需产品信息架构决策）。
- App 图标【建议稿】：白底彩色图形标为首选，图形标占画布 60%；深色模式用墨黑底；不放字标、小奈或文字。
- 小程序【建议稿】：头像用图形标；分享卡片 5:4，左上放反白横版 Logo；启动页品牌露出 ≤ 1.5s，不做广告式动画。
- 小奈同学（沿用）：可折叠的 AI 伙伴；关键动作前需用户确认；能力快测是建议，不是认证。

## 设计 Token（结构沿用，色值以视觉板 SVG 为准）
直接引用 `assets/tokens/tokens.css` 或 `tokens.json`，不要在业务代码里硬编码相近色值。旧变量名（--nx-purple-hover、--nx-orange、--nx-dark-navy 等）保留为兼容别名，已指向新色值。

## 必须
- 每个区域只有一个紫色主按钮（高 44px）。
- 卡片用 1px 边框与间距分隔，不用常规阴影。
- 图标统一 Phosphor，描边一致。
- 焦点可见、触控目标 ≥ 44px、对比度 AA。
- 桌面 / 中屏 / 390px 移动端都检查，移动端不是等比缩小；无横向溢出。
- 证据分级表述：自述 / 来源链接 / 过程证据 / 已复核 / 已认证。

## 禁止
- 界面装饰渐变、渐变按钮。
- 每块内容都做成圆角白卡片。
- 橙色作为第二主按钮。
- 假数据、假合作方 Logo、就业 / 薪资承诺。
- AI 自动生成正式认证结论。
- 暗示系统会静默读取用户外部账号。
