# 02 Logo

**唯一来源：品牌视觉板 SVG 原文件（用户确认：以 SVG 原文件为准）。**

构成：12 个圆角方块组成的"像素星芒"图形标（Logo 渐变 #7417FF 自 25% 起 → #FE6702）+ 定制字标"奈势AI"（#262626）。只用官方矢量，不重绘、不重打字。Logo 渐变只属于 Logo，不用于任何其他元素。

## 视觉板实测比例（以图形标高 H 为单位）
- 图形标 H × H；字标高 ≈ 0.60 H，与图形标垂直居中
- 图形标与字标间距 ≈ 0.21 H；横版组合宽高比 ≈ 3.4 : 1（659 × 194）
- 视觉板 Logo 卡内上下留白 ≈ 0.92 H（推荐留白）；最小安全空间 X = 0.5 H（沿用）

- 彩色版不放在奈势紫、薰衣草紫、珊瑚橙等中高饱和底上；渐变标不放深紫底（起点紫与底色太近），深紫底用全白版。
- 不提供、也不允许制作"单色紫图形标"。
- 选择顺序：横版 → 竖版 → 图形标。图形标单独出现时，同一视野内应能看到"奈势AI"全称。

## 安全空间与尺寸
- X = 图形标高度 × 0.5，四周 X 内不放其他元素（沿用）
- 屏幕最小：横版高 24px（顶栏推荐 28–32px），竖版高 48px，图形标 16px
- 印刷最小【新增规范】：横版宽 25mm，竖版宽 15mm，图形标 6mm；刺绣/丝印/雕刻图形标 ≥ 10mm 并打样

## 在图片上【新增规范】
放在平静区域（通常左上）；对比不足时加深色渐隐或白色底板（底板圆角 = 底板高 × 0.2）；不压人脸、文字、高频纹理。

## 错误用法
拉伸压扁；旋转倾斜；改色；字标加渐变或图形标改单色；投影/发光/描边；调换图形与字标；用其他字体重打；彩色版放紫色或低对比底；放复杂图片上；降低透明度（水印除外）；加框或徽章外壳；小奈或其他元素压住 Logo；**【v1.2】放在菱形网格 / 像素底纹上**（底纹与图形标的像素星芒"打架"，Logo 显得杂乱）；**【v1.2】搭配已停用的台阶 / L 形像素方块**。Logo 背景一律用干净的纯色或平静的照片区域。

## 英文字标【缺口】
暂无官方英文字标。英文材料使用标准横版 Logo，正文写 NexAI；不得用字体自拼"图形标 + NexAI"。
