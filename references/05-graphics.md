# 05 图形元素

## 像素方块辅助图形【v1.2 停用】
像素方块组成的 **L 形 / 台阶形**辅助图形（角标、堆叠、分隔条、加载）以及 **菱形网格（像素场）底纹** 全部停用：
- 不在任何新物料中使用，旧版 `graphics/pixel-*.svg` 已从素材包与本 Skill 删除；
- Logo 不放在菱形网格 / 像素底纹上（会让 Logo 显得杂乱）；
- 像素元素只保留在 Logo 图形标本身与小奈的犄角、袖标、口袋图案中。
需要装饰时：用留白、纯色块（墨黑 / 奈势紫 / 雾紫 / 白）、大标题和小奈延展动作。

## 图标（沿用）
产品用 Phosphor Icons；24px 网格、描边 1.5–1.7px、圆角端点；同一画面只用一套。营销放大使用同风格；不用拟物、多色、渐变图标。

## 摄影
真实的人做真实的事（写代码、讨论、展示作品）；暗部偏墨黑、点缀暖光；留出标题平静区；多元自然。禁用竖大拇指摆拍、蓝光机器人手、数字大脑类图库。

## 插画
以小奈 3D 形象（标准姿态 + v1.2 延展动作 / 表情）为核心，不另起扁平人物插画体系；信息图用品牌色 + 中性色，线宽 1.5–2px。

## AI 生成图
- 可以：背景、场景、氛围图；概念草图；以官方小奈为基础的构图参考（需设计复核）
- 不可以：生成/改画 Logo；未经品牌组审核的新小奈对外发布；生成真实人物肖像、合作方标志、证书奖牌；带虚假数据或文字的截图
- 流程：用公司授权工具；检查手指/文字/透视瑕疵；必要时标注"AI 生成示意图"；源图与提示词存 `05_图片/AI生成`
