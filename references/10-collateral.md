# 10 对外宣传物料

统一规则：Logo 左上或居中；官网 nexai.link 必出现；口号与使命原文使用；联系方式按个人填写；不加未经确认的数字和称号。

## 名片【新增规范】
- 正面白底：横版彩色 Logo、姓名、职位、手机、邮箱、官网。
- 背面墨黑：竖版反白 Logo + 口号"一起热爱，一起成长！" + nexai.link。
- 企业邮箱域名待提供，未确认前不得自拟。

## 宣传单页 · 海报 · 画册【新增规范】
统一骨架：Logo 区 → 标签 → 大标题 → 说明 → 小奈 → 底部官网条。

## 印刷规格【新增规范】
| 物料 | 规格 | 底色 | 要点 |
|---|---|---|---|
| 名片 | 90×54mm，出血 2mm，300g 以上白卡 / 特种纸 | 正白 / 背墨黑 | 文字距裁切线 ≥ 5mm；可加局部 UV Logo |
| 宣传单页 | A4 / A5，出血 3mm，157g 铜版纸 | 白 | 正面讲一个结论，背面 3 个要点 + 二维码 |
| 海报 | 2:3（如 60×90cm），出血 3mm | 墨黑 / 雾紫 | 标题 ≥ 版面宽 8%；时间地点信息区固定在底部 |
| 画册 | A4 竖版，封面 250g，内页 157g | 雾紫封面 | 封面只放竖版 Logo + 使命 + 小奈；内页 12 栏网格 |
| 二维码 | ≥ 25×25mm，四周留白 ≥ 2mm | 白底黑码 | 中心可放图形标（≤ 码宽 20%）；码下写用途 |

印刷文件用 CMYK 输出并打样（色值见 03-color，属参考值）。

## 邮件签名【新增规范】
全员统一，不加个人格言、表情、动图。纯文本版：

```
姓名　职位 · 部门
奈势AI（NexAI）
手机 +86 000 0000 0000　|　https://nexai.link
一起热爱，一起成长！
```

HTML 版签名中的图形标使用 `assets/logo/png/nexai-mark-color@256w.png`，显示 56×56px。
