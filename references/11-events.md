# 11 活动物料

目标：远看认得出、近看读得清、拍照好看。主背景统一墨黑 #262626，纯色背景不加像素场 / 菱形底纹，小奈做互动点（不压文字），Logo 永远在视线高度。

## 背景板【新增规范】
主信息放在上 2/3；下 1/3 为讲台和人群遮挡区。Logo 高 ≥ 画面高 8%；底部官网 nexai.link。

## 易拉宝与展台【新增规范】
- 易拉宝：Logo 在顶部 20% 区，关键标题在 1.2–1.8m 视线高度；底部 20cm 不放信息。
- 展台：背墙反白 Logo，接待台彩色 Logo，屏幕与 Logo 分区。

## 胸牌 · 门票 · 手提袋 · 礼品【新增规范】
礼品优先用图形标 + 口号的简洁组合；小奈用于贴纸、徽章、玩偶等情感类礼品。

## 规格
| 物料 | 规格建议 | 规则 |
|---|---|---|
| 背景板 | 常用 5×2.5m / 6×3m，喷绘或布幕 | Logo 高 ≥ 画面高 8%；合作方 Logo 统一放底部单色条，尺寸小于奈势AI |
| 易拉宝 | 80×200cm | 只讲一件事；底部 20cm 不放信息；官网放底部色条 |
| 展台 | 3×3m 标摊起，背墙 + 接待台 | 背墙墨黑；接待台白色 + 彩色 Logo；灯箱打样保证紫色不偏蓝 |
| 胸牌 | 90×130mm，挂绳品牌紫 | 身份色条：紫 = 嘉宾，墨黑 = 工作人员，橙 = 媒体；姓名 ≥ 28pt |
| 门票 | 主票 + 副票，或电子票 1080×1920 | 二维码 ≥ 25mm；时间、地点、座位三项固定位置 |
| 手提袋 | 本色帆布 / 白卡纸袋 | 单面图形标 + 口号，或横版 Logo；单色丝印用全白或单色黑版 |
| 礼品 | 马克杯、T 恤、贴纸、徽章、笔记本、玩偶 | 一件一个主元素；刺绣 / 丝印图形标 ≥ 10mm；先打样 |

背景板、展台、合作方 Logo 并列属 A 级审批（见 13-governance）。
