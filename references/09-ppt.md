# 09 PPT

统一使用 `奈势AI-PPT模板-v1.2.pptx`（https://brand.nexai.link/downloads.html 下载；为保持仓库轻量不放在 `assets/` 里）（16:9，主题字体 MiSans）。模板含 6 页示例版式，复制示例页再改内容，不要从空白页自己拼。

## 示例版式（v1.2）
| 版式 | 构成 |
|---|---|
| 封面 | 墨黑 + 反白 Logo + 口号 + 官网（固定），小奈在右侧独立区域 |
| 目录 | 左侧雾紫栏，最多 6 项 |
| 章节 | 奈势紫满版，章节号 + 一句话 |
| 内容 | 左文右图（小奈放在右侧雾紫卡片中，不压文字），页脚图形标 + 官网 + 页码 |
| 数据 | 浅灰底，一张图 + 一个关键数字 + 来源 |
| 结尾 | 竖版 Logo + 口号 + 使命 + nexai.link，挥手小奈在独立卡片中 |

## 版式
- 16:9，边距 0.6 英寸。
- 标题写结论，不写"概述""背景"等标签。
- 每页一个结构：左文右图 / 一张图表 / 一个大数字 / 流程。
- 正文 ≤ 3 个要点，每条 ≤ 2 行。

## 字体与颜色
- 标题 30–44pt 粗体，正文 16–20pt，注释 10–12pt。
- MiSans（未安装时回退苹方 / 微软雅黑）；对外发送导出 PDF 并内嵌字体。MiSans 下载：https://hyperos.mi.com/font
- 图表主色紫，强调 1 处用橙，其余灰。
- 不使用渐变底、艺术字、3D 图表、像素方块装饰；小奈不压文字。

## 固定内容
- 封面与结尾的口号"一起热爱，一起成长！"、使命"成就每一位AI创造者"、官网 nexai.link 不可修改或删除。
- Logo 只用母版里的，不另贴。
- 对外发送导出 PDF，文件名按 13-governance 规则。
- 合作方 Logo 放内容页，不上封面（联合发布除外，按 A 级审批）。
