# 12 办公环境

基调：浅灰 #F6F6F8、白色、墨黑 #262626；紫色只做点缀，避免"满墙紫"。

## 前台 Logo 墙【新增规范】
墙面暖灰，横版彩色 Logo 立体字，下方为使命原文"成就每一位AI创造者"。

## 门牌 · 导视 · 工位 · 文化墙【新增规范】
所有标识文字使用 MiSans。门牌左侧 12mm 紫色条做识别；导视墨黑底白字，箭头在前；文化墙使用已确认的使命、愿景、口号原文：
- 使命：成就每一位AI创造者
- 愿景：全球领先的下一代AI共创平台
- 口号：一起热爱，一起成长！

## 规格要点
| 项目 | 规格 | 规则 |
|---|---|---|
| 前台 Logo 墙 | 立体字厚 20–30mm；Logo 中心离地 1.6–1.8m | 宽度 ≤ 墙宽 50%；图形标保留渐变（UV 打印或分色拼接）；背光先打样 |
| 门牌 | 300×130mm 亚克力 / 铝板 | 中文 36–44pt 粗体，英文为中文 50%；离地 1.5m |
| 导视总牌 | 600×900mm 起 | 墨黑底白字；箭头 + 中文 + 英文；中文 28–32pt |
| 工位牌 | 200×60mm | 姓名 + 部门 + 工位号；头像可用本人照片或小奈 v1.2 圆形头像 |
| 文化墙 | 按墙面定制 | 使命、愿景、口号原文；真实项目照片需当事人同意 |
| 玻璃防撞条 | 离地 1.0m / 1.5m 两道，高 80–100mm | 纯色磨砂贴膜 + 白色横版 Logo（不使用像素图案） |
