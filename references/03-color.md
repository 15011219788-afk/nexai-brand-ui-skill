# 03 色彩

**唯一来源：品牌视觉板 SVG 原文件（用户确认：以 SVG 原文件为准）。** 视觉板只给出色块，以下角色分配为【新增规范】，色值本身为官方。

一组紫色色阶负责身份，墨黑与灰白构成空间，珊瑚橙是唯一强调色。Logo 渐变只属于 Logo。

- #000000 在视觉板中只是白色 Logo 卡的 1px 外框线，不作品牌色；仅用于单色黑 Logo（黑白印刷）。
- Logo 渐变：#7417FF（25% 处起）→ #FE6702，`--nx-gradient-logo`。**只存在于 Logo 图形标内**；#7417FF、#FE6702 不得作为按钮、文字、底色、像素图形或任何独立颜色使用。
- 功能色（视觉板未定义，沿用产品设计系统，仅限产品界面状态）：成功 #08755F、警示 #B45F06、危险 #B42318。不进入品牌/营销/印刷/活动/办公物料。
- 旧 v1.0 变量名（--nx-purple-hover、--nx-orange、--nx-dark-navy、--nx-purple-soft 等）在 tokens.css 中保留为兼容别名，已指向新色值，新代码请用上表名称。

## 比例【新增规范】
白/浅灰 55% · 墨黑 20% · 奈势紫 ≤ 10% · 薰衣草紫/雾紫 ≈ 8% · 深紫少量 · 珊瑚橙 ≤ 5%（每版一处）。营销物料可用墨黑作主背景（≤ 60%，同视觉板深色卡）。

## 对比度（WCAG AA：正文 ≥ 4.5，大字 ≥ 3）
- 白 / #6857E7 = 5.11 ✓（奈势紫按钮白字）
- 白 / #3C237C = 12.18 ✓；白 / #262626 = 15.13 ✓
- #BBBBFE / #262626 = 8.40 ✓（墨黑底强调文字）
- #6857E7 / #262626 = 2.96 ✕ 墨黑底不用奈势紫文字
- #262626 / #FF604A = 5.06 ✓；白 / #FF604A = 2.99 ✕ 珊瑚橙底用墨黑字
- #FF604A / 白 = 2.99 → 珊瑚橙只做色块、图形或 ≥ 24px 大字，不作白底正文色
- #6857E7 / #F1F0FD = 4.54 ✓；#6E6E73 / 白 = 5.07 ✓；#6E6E73 / #F6F6F8 = 4.70 ✓

## 印刷
#6857E7 与 Logo 渐变紫 #7417FF 都超出四色色域，印刷偏灰属正常；背景板、Logo 墙、礼品等重要物料由品牌组指定专色，以色卡 + 实物打样确认，同批物料同一印厂。
