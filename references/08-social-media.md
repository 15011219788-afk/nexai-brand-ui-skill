# 08 社会化媒体与自媒体

所有官方账号共用一套头像、简介格式和版式骨架：Logo 位置固定、标题大而少、小奈在独立区域做情绪、不压文字。模板见 `assets/social/`（HTML 可改字，按 `<meta name="size">` 尺寸截图导出）。

## 头像与简介【新增规范】
- 官方主账号：白底彩色图形标，占画布 60%，所有平台统一（`avatar-official-400x400.html`）。
- 小奈人设号 / 社群：雾紫底小奈头像，仅限品牌组授权账号（`avatar-xiaonai-400x400.html`）。
- 账号名：奈势AI；英文平台：NexAI；子账号：奈势AI·xx（如 奈势AI·社区）。
- 简介格式：第 1 行使命"成就每一位AI创造者"；第 2 行一句话说明账号内容；第 3 行官网 nexai.link（可点链接处填 https://nexai.link）。
- 简介中不使用未经确认的排名、数据、合作方。

## 版式骨架
1. Logo 固定左上（深色底用反白版）。
2. 一个标签 + 一个大标题（≤ 16 字，2–3 行）。
3. 小奈占右侧或右下，不遮挡标题。
4. 底部官网 nexai.link。

## 视频【新增规范】
- 片头（≤ 2 秒，可省略）：墨黑底，图形标淡入后出现字标；或直接用标题画面开场。
- 片尾（3 秒）：竖版反白 Logo + 口号"一起热爱，一起成长！" + nexai.link，小奈可在侧边（`video-endcard-1920x1080.html`）。
- 字幕：MiSans Medium，白字 + 柔和黑色描边/阴影；竖屏 48–60px（1080 宽），横屏 40–48px；每行 ≤ 16 字、最多 2 行；位于画面 65–75% 高度，避开底部 340px；中英文混排加空格；不用花字、彩虹字。
- 水印：右上角全白横版 Logo，高度 = 画面短边 3.5%，透明度 85%。
